Exercício: Acessando Dados do Objeto 'filme'

O objeto a ser analisado é:

const filme = {
    nome: "Auto da Compadecida", 
    ano: 2000, 
    elenco: [
        "Matheus Nachtergaele", "Selton Mello", "Denise Fraga", 
        "Virginia Cavendish"
    ], 
    transmissoesHoje: [
        {canal: "Telecine", horario: "21h"}, 
        {canal: "Canal Brasil", horario: "19h"}, 
        {canal: "Globo", horario: "14h"}
    ]
}

As respostas para cada item serão exibidas no console do navegador.

(Pressione F12 ou Ctrl+Shift+I para abrir o console).
