Exercício: Filtrando e Mapeando Produtos

Dado um array de objetos de produtos, utilizamos filter() e map() para criar um novo array contendo apenas os nomes dos produtos da categoria "limpeza". 

// Estrutura dos dados de entrada:
const produtos = [
   { nome: "Alface Lavada", categoria: "Hortifruti", preco: 2.5 },
   { nome: "Guaraná 2l", categoria: "Bebidas", preco: 7.8 },
   { nome: "Veja Multiuso", categoria: "Limpeza", preco: 12.6 },
   // ... e assim por diante
]

O array resultante será exibido no console do navegador.

(Pressione F12 ou Ctrl+Shift-I para abrir o console).
