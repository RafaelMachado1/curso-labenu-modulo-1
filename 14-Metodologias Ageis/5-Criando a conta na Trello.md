## 5.1 - Criação de Conta Gratuita no Trello

A criação de conta no Trello é muito simples, basta você seguir as etapas disponibilizadas na própria plataforma, sendo possível criar acessos tanto com uma referência direta do e-mail de cadastro, ou conectar e registrar diretamente com uma conta google.
Acesse, o link abaixo para criar sua conta na plataforma.

### 5.2 - Realizando uma cópia do template que será utilizado no Exercício

1. Primeiramente precisamos acessar o link de referência para nosso template, disponibilizado no próprio README do exercício que faremos na parte da tarde.
Esteja logado já no Trello para realizar a cópia desse template diretamente para sua Workspace.
    
    [Atividades de Metodologias Ágeis](https://trello.com/b/mDl6D3g6/atividades-de-metodologias-ágeis)
    
2. Ao acessar o link irão se deparar com um botão, com a seguinte mensagem: “Create board from template”, clique nesse botão.

    
    ![Untitled](./img%20e%20vídeos/Untitled5.webp)
    
3. Agora só precisamos finalizar a cópia deste template para nós, validando as informações do board que desejamos manter e dando um nome para ele, como demonstrado na imagem abaixo.

    
    ![Untitled](./img%20e%20vídeos/Untitled6.webp)
    
4. Nome definido e mantenimento dos cards apresentados no template? Agora só basta clicarmos em “Create”.

    
    ![Untitled](./img%20e%20vídeos/Untitled7.webp)
    
5. Realizado as etapas anteriores, repare que agora você é será o admin desse board! Agora você poderá interagir com o board e gerenciar as tasks!
    
    ![trello-admin.gif](./img%20e%20vídeos/trello-admin.gif)
    
6. Como faço para verificar todos os boards de que tenho acesso ou controle? 
Para isso, precisamos clicar no botão “Trello”, localizado no canto superior esquerdo da plataforma, logo em seguida acesse sua Workspace e o campo “Boards”, todos localizados ao canto esquerdo da tela. Segue uma animação abaixo, demonstrando esse fluxo!

    
    ![trello-admin.gif](./img%20e%20vídeos/trello-admin1.gif)
