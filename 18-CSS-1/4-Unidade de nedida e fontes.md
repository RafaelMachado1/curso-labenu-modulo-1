# Unidades de medida e fontes

# Unidades

Vamos explorar algumas das unidades de medida que o CSS permite utilizar para definir posições e tamanhos. Em geral, essas unidades são divididas entre **absolutas** e **relativas**. A seguir, vamos apresentar as unidades mais comuns de cada tipo.

## Unidades Absolutas

### `px`

Indica a quantidade de pixels que deve ocupar. Um pixel é o menor ponto de exibição em uma tela.

### `pt`

É utilizada para indicar o tamanho da fonte em relação à resolução da tela

## Unidades Relativas

### **`%`**

indica uma porcentagem do tamanho relativo ao tamanho do elemento pai. Por exemplo, se a altura da div-filha for definida como 50%, ela será a metade da altura da div-mãe.

### **`vw`**

Cada 1vw **equivale a 1% da largura da tela.**

### **`vh`**

Cada 1vh **equivale a 1% da altura da tela.**

### **`em`**

Define o tamanho do texto com base no tamanho da fonte do **elemento pai.**

### `rem`

Define o tamanho do texto com base no tamanho da fonte do **elemento raiz do documento HTML**.

Existem outras unidades de medida menos comuns que podem ser úteis em situações específicas. No entanto, para este momento, vamos nos ater às unidades que já foram apresentadas.

## Fontes

Os arquivos CSS podem ser utilizados para alterar diversas propriedades dos elementos. Vamos dar uma olhada nas propriedades mais comuns:

### `font-family`

Essa propriedade define qual fonte será usada para o elemento.

### `font-size`

Essa propriedade define o tamanho da fonte do elemento. O tamanho padrão é 16px para elementos de texto.

### `color`

Essa propriedade define a cor do texto do elemento.

### `background-color`

Essa propriedade é semelhante à propriedade **`color`**, mas define a cor do fundo do elemento selecionado.
